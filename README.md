# Personal Portfolio Website

A simple and professional **frontend portfolio website** built using **React.js**. The website presents my profile, technical skills, projects, education, certifications, internship experience, and contact details.

## 🚀 Features

* Responsive portfolio design
* Home and introduction section
* About Me section
* Technical Skills section
* Projects showcase
* Education details
* Certifications
* Internship experience
* Contact information
* Smooth navigation between sections

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

### 2. Open the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal to view the portfolio.
